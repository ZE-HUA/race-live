# Race Live — 多人即時位置與車速

手機打開網頁，輸入名字和房間代碼，同一個房間的人會在地圖上即時看到彼此的位置、方向和車速。

- 網址：https://ze-hua.github.io/race-live/
- 即時同步：公開 MQTT 伺服器（broker.hivemq.com，WebSocket over TLS），每秒上傳一次位置
- 地圖：Leaflet + OpenStreetMap
- 限制：螢幕關閉或切到背景時會停止定位；知道房間代碼的人都能看到位置

## 房主與房間
- **第一個進入房間的人是房主 👑**，之後加入的人是一般玩家：會出現在地圖上，但不能開始／停止記錄。
- 玩家離開 → 立刻從所有人的地圖上消失（斷線沒通知的話，30 秒內消失）。
- **房主離開 → 房間結束**，所有人收到通知並回到首頁。之後再用同一個代碼進來，就是開一間新房間。
- 房主重新整理或短暫斷線：有 20 秒寬限期，回來後還是房主，進行中的記錄會接續。
- 兩個人幾乎同時建立同一間房：比較早的那位當房主。

## 記錄與回放
- 房主按「● 開始記錄」，房間內所有人都會看到「記錄中」。
- 紀錄存在**房主手機的瀏覽器**（IndexedDB）裡，每 5 秒寫入一次。
- 「紀錄」清單可以回放（1×–32× 倍速、拖拉時間軸、點車手讓鏡頭跟著他），也可以匯出 CSV（Excel）或 GPX（通用軌跡格式）。
- 限制：房主的網頁必須一直開在前景，切到背景期間收不到其他人的位置，紀錄會有空白。

## 影片輸出（.mp4）
- 「紀錄」清單 → 🎬 影片：選橫式/直式、播放速度（1×–16×）、地圖樣式，在手機上直接產生 MP4。
- 畫面：固定鏡頭框住整場範圍，畫出軌跡（跑過的部分會亮起）、每台車的名字與車速、即時車速排行、經過時間。
- 用 WebCodecs（H.264）+ mp4-muxer 編碼，比實際時間快；不支援的瀏覽器會改用即時錄製。
- iPhone 按「儲存／分享」→「儲存影片」即可存進相簿。
