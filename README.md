# Race Live — 多人即時位置與車速

手機打開網頁，輸入名字和房間代碼，同一個房間的人會在地圖上即時看到彼此的位置、方向和車速。

- 網址：https://ze-hua.github.io/race-live/
- 即時同步：公開 MQTT 伺服器（broker.hivemq.com，WebSocket over TLS），每秒上傳一次位置
- 地圖：Leaflet + OpenStreetMap
- 限制：螢幕關閉或切到背景時會停止定位；知道房間代碼的人都能看到位置

## 房主與房間
- **第一個進入房間的人是房主 👑**，之後加入的人是一般玩家：會出現在地圖上，但不能開始／停止記錄。
- 玩家離開 → 立刻從所有人的地圖上消失（斷線沒通知的話，30 秒內消失）。
- **房主離開 → 房間結束**，所有人收到通知並回到首頁。之後再用同一個代碼進來，就是開一間新房間。
- 房主斷線（例如山區沒訊號）：**房間保留 10 分鐘**，大家照常定位、記錄；房主回來後還是房主，進行中的記錄會接續。只有房主親自按「離開」才立刻結束。
- 兩個人幾乎同時建立同一間房：比較早的那位當房主。

## 玩法：點對點計時
- 房主按右上角「一般」→ 選「🏁 點對點計時」，設定起點、終點（在地圖上點選，或「用我的位置」）與感應範圍（15／30／50 m），按「套用到房間」。
- 還沒套用的設定會保留：可以先到起點按「用我的位置」，關掉視窗開到終點再設定。
- **搜尋地點**：起點／終點都有「🔍 搜尋」，同時查 OpenStreetMap（地標準）和 Mapbox（地址準），合併去重後顯示名稱、地址和距離。選了搜尋結果後地圖會移到該位置並放一個**可拖曳的圖釘**，拖曳或點地圖微調（感應圈即時跟著移動），按「確定」才設定；「地圖點選」也用同樣的圖釘。移動超過 60 m 會重新查路名。用「我的位置」設定的點會自動查出路名。
- **我的路線**：設定好的路線可以命名「💾 儲存」到這支手機（最多 50 條），之後「載入」再套用；同名會詢問是否覆蓋。一般玩家按「🏁 計時」也能把房主的路線存到自己手機。
- 每支手機各自判斷：**離開起點圈自動開始計時，進入終點圈自動停止**。用前後兩個 GPS 點內插穿越圈線的時間，誤差約零點幾秒。
- 可以重複跑，排行依每人最佳成績排序；計時中的人會即時顯示時間。成績用 retained 訊息分享，重新整理或晚加入也看得到。換路線會清空成績。
- 錄影畫面的排行也會換成成績，車速上方顯示計時。
- 切回「一般」就恢復原本的車速排行。

## 記錄與回放
- 房主按「● 開始記錄」，房間內所有人都會看到「記錄中」。
- 紀錄存在**房主手機的瀏覽器**（IndexedDB）裡，每 5 秒寫入一次。
- 「紀錄」清單可以回放（1×–32× 倍速、拖拉時間軸、點車手讓鏡頭跟著他），也可以匯出 CSV（Excel）或 GPX（通用軌跡格式）。
- **斷線補傳**：房主記錄期間，每位玩家的手機也會記一份自己的軌跡（紀錄清單裡的「🧭 我的軌跡」），每 15 秒把房主還沒確認收到的點送過去；房主合併進紀錄後回傳確認。不論玩家或房主哪一方沒訊號，網路恢復後空白都會補齊（記錄結束後 15 分鐘內傳到的也會合併）。
- 位置訊息帶有送出時間，房主會依各手機的時鐘差換算成同一個時間軸；斷線期間的即時位置不會延遲補送到地圖上。
- 限制：網頁必須一直開在前景，切到背景或鎖定螢幕時手機會停止定位，那段時間本身就沒有軌跡。

## 影片輸出（.mp4）
- 「紀錄」清單 → 🎬 影片：選橫式/直式、播放速度（1×–16×）、地圖樣式，在手機上直接產生 MP4。
- 畫面：固定鏡頭框住整場範圍，畫出軌跡（跑過的部分會亮起）、每台車的名字與車速、即時車速排行、經過時間。
- 用 WebCodecs（H.264）+ mp4-muxer 編碼，比實際時間快；不支援的瀏覽器會改用即時錄製。
- iPhone 按「儲存／分享」→「儲存影片」即可存進相簿。

## 錄影（行車記錄器）
- 地圖下方 🎥：用手機鏡頭錄影，畫面上即時疊加日期時間、車速、房間排行（前 5 名）和小型線路圖（北朝上、無底色，自己與其他人跑過的路線，自動縮放）。
- 可切換前／後鏡頭、廣角 0.5× / 正常 1×、開關收音（預設開啟）、關掉疊加資訊錄乾淨畫面。直拿錄 720×1280、橫拿錄 1280×720。
- 廣角：iPhone 直接使用「超廣角」鏡頭；Android 多半改用鏡頭縮放縮到最廣；瀏覽器沒開放的手機會顯示為不可用。
- 錄完可預覽，按「儲存／分享」→「儲存影片」存進相簿。影片只存在當下畫面，離開前要儲存。
- 錄影時位置分享、房主記錄都照常進行；但畫面必須保持開著，鎖定螢幕會中斷錄影。
- **錄影軌跡**：按下錄影時，會同時把自己的 GPS 軌跡與車速存成一筆「🎥 錄影軌跡」紀錄（不論是不是房主），跟影片檔名配對，可以回放、匯出 CSV／GPX、輸出軌跡影片。影片沒存或錄影期間沒有 GPS 也不影響（沒有 GPS 就不留空紀錄）。
